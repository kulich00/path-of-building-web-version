# Статус проекта

## Опубликованная версия

Веб-приложение доступно по адресу: [Path of Building Web](https://path-of-building-web.lolkek22232.chatgpt.site).

Последняя известная версия Sites: 12. Это метаданные публикации; они не заменяют Git-историю исходников.

## Что подтверждено в текущем проектном контексте

- импорт PoB-кода с декодированием Base64URL, zlib и XML;
- извлечение основных сведений о персонаже и предметах;
- корректный выбор активного умения по данным PoB;
- просмотр дерева с поиском по имени, эффекту и ID;
- отдельное отображение keystones, узлов восхождения, кластерных пассивов и mastery;
- разрешение выбранного эффекта mastery по TreeData.
