# Статус проекта

## Исходный код

Исходники опубликованного приложения перенесены в этот репозиторий из Sites checkout. Перенесённая версия соответствует Sites version 12, source commit `06f62ff3171b03e7e6490aa808394ae798925feb`.

## Реализовано

- импорт PoB-кода с декодированием Base64URL, zlib и XML;
- извлечение основных сведений о персонаже, активном навыке и предметах;
- просмотр дерева с поиском по имени, эффекту и ID;
- отдельные категории keystones, узлов выбранного восхождения, обычных пассивов, кластеров и mastery;
- отображение крупных кластерных пассивов и выбранных эффектов mastery.

## Технологический выбор

- Фронтенд: JavaScript и React; JSX используется в компонентах.
- Следующий архитектурный этап: спроектировать и реализовать бэкенд на Go. Сейчас собственного бэкенда нет.

## Проверка

10 октября 2026 выполнено:

- `npm run install:ci` — успешно, зависимости установлены по lock-файлу;
- `npm test` — успешно: production build прошёл, тест HTML-ответа Worker прошёл (1/1).

Сборка выдала предупреждение Vinext о статическом определении маршрутов, но завершилась успешно и проверка артефакта прошла.
