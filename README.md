# Path of Building Web

Веб-инструмент для просмотра сборок Path of Exile из экспортного кода Path of Building.

**Опубликованная версия:** [path-of-building-web.lolkek22232.chatgpt.site](https://path-of-building-web.lolkek22232.chatgpt.site)

> **Состояние репозитория:** сейчас здесь находится документация проекта. Исходники опубликованного приложения ещё не перенесены в этот GitHub-репозиторий; поэтому запуск и сборка из репозитория пока недоступны.

## Возможности опубликованного MVP

- Импорт кода PoB и разбор XML после декодирования Base64URL и zlib.
- Отображение класса, восхождения, уровня, основного умения, версии дерева и предметов.
- Выбор основного умения с учётом выбранной группы и активного камня PoB, а не первого камня в списке.
- Просмотр выделенных пассивов с поиском по имени, описанию эффекта и ID.
- Разделение дерева на keystones, пассивы восхождения, обычные пассивы, cluster jewel пассивы и mastery.
- Отображение крупных пассивов кластерных самоцветов и текста выбранных эффектов mastery на основе данных TreeData соответствующей версии.

## Границы текущего этапа

MVP импортирует и отображает данные сборки. Он пока не заменяет настольный PoB:

- расчёты DPS и защиты через Lua-движок ещё не подключены;
- полная редактируемая геометрическая карта дерева не реализована;
- результаты импорта необходимо сверять с исходным билдом в PoB.

## Базовая совместимость

Первая версия проекта ориентирована на **Path of Exile 1**, Path of Building Community и выбранный для MVP базовый набор PoB **2.67.2 / PoE 3.29**. Данные дерева должны подбираться по версии дерева из импортируемой сборки.

## План работ

1. Перенести исходный код опубликованного приложения в этот репозиторий.
2. Добавить инструкции установки, запуска, тестирования и сборки, сверенные с фактическими файлами проекта.
3. Подключить Lua-движок PoB через отдельный calculation service и сравнивать расчёты с настольным PoB.
4. Реализовать полную геометрию пассивного дерева и редактирование билда.

## Лицензирование

Лицензии исходников приложения и используемых данных нужно проверить по фактическим файлам проекта перед публикацией кода. Path of Building Community и его сторонние зависимости могут иметь отдельные условия и уведомления.
