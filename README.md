# Path of Building Web

Веб-инструмент для импорта и просмотра сборок Path of Exile из кода Path of Building.

**Онлайн-демо (Cloudflare Workers):** [pob-web.lolkek22232.workers.dev](https://pob-web.lolkek22232.workers.dev)

## Возможности

- Декодирование кода PoB: Base64URL → zlib → XML.
- Отображение класса, восхождения, уровня, основного умения, версии дерева и предметов.
- Выбор основного умения по выбранной группе и активному камню, с исключением камней поддержки.
- Разбор выделенных пассивов на обычные узлы, keystones, узлы выбранного восхождения, cluster jewel пассивы и mastery.
- Карточки кластерных самоцветов с крупными пассивами.
- Расшифровка выбранного эффекта mastery с данными TreeData.
- Поиск по названию узла, эффекту или ID.

## Запуск локально

Требуется Node.js `>=22.13.0` и Linux с `flock`, `curl` и GNU `timeout`.

```bash
npm run install:ci
npm run dev
```

Проверки и сборка:

```bash
npm test
npm run build
```

`npm test` собирает приложение и проверяет HTML-ответ Worker. Сборочные скрипты создают временные данные в `.sites-runtime/`.

Фронтенд использует React и JavaScript: клиентские компоненты находятся в `.jsx`, модули без JSX — в `.js`. TypeScript оставлен только в конфигурации и инфраструктуре сборки. Текущий MVP опубликован на Cloudflare Workers и пока не имеет отдельного Go-бэкенда.

**Планируемый бэкенд:** Go. Следующий этап — выделить серверную логику и API в Go-сервис и связать его с веб-интерфейсом. Расчёты DPS и защиты пока не реализованы.

## Структура проекта

- `app/page.jsx` — интерфейс, импорт кода и представление дерева.
- `app/globals.css` — стили приложения.
- `app/layout.jsx` — корневой layout и метаданные.
- `public/` — статические ресурсы.
- `tests/` — тесты рендеринга.
- `scripts/` — установка зависимостей, сборка и проверка артефакта.
- `.openai/hosting.json` — настройки проекта Sites.

## Совместимость и ограничения

Проект ориентирован на Path of Exile 1 и Path of Building Community. TreeData подбирается по версии дерева из сборки. Целевая база первой версии — PoB 2.67.2 / PoE 3.29.

Приложение импортирует и показывает данные сборки. Расчёты DPS и защиты через Lua и полноценное редактирование геометрической карты дерева пока не реализованы.
